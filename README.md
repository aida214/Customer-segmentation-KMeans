# Customer-segmentation-KMeans
Customer Segmentation using K-Means Clustering
## Objective
To group customers into different segments based on their spending behaviour and purchase frequency.
## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- Matplotlib
## Project Steps
- Data processing
- EDA
- Elbow Method
- K-Means clustering
- Customer segmentation visualization
## Result
The customers were divides into different groups based on their purchasing behaviour.
